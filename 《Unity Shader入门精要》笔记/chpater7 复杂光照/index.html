    • 1.1 前向渲染

    1. 渲染路径¶

    Unity有三种渲染路径：前向渲染，延迟渲染，顶点照明

    渲染路径一般在Pass或者Subshader中 

    Tags {"LightMode"="Forwardbase"}

    前向渲染： 1. forwardbase:一般处理最亮的平行光和光线顶点着色 2. forwardadd:一般用于聚光灯，点光源等光源进行片元着色

    延迟渲染： 一般用于处理多个光源重叠空间的渲染，不对每个光源执行pass,使用G缓冲后只执行一次pass。

    1.1 前向渲染¶

    前向渲染有两种Pass：ForwardBase, ForwardAdd

    1. Base Pass无论有多少光源，只执行一次，主光源和非重要光源就在BasePass中渲染。
    2. Add Pass会为每一个除主光源外的逐像素处理的光源执行一次。

    2. 复杂光照¶

    2.1 不同光照处理¶

    1. 最亮的平行光或某一个其他光源在BasePass中按逐像素进行渲染，其他光源如非重要光源、SH球谐光会在BasePass中按照逐顶点方式渲染。
    2. unity选取主光源顺序：最亮平行光 > 最近其他光源，在unity有关于光源评分的机制，评分最高的选为主光源，平行光优先级大于其他光源。
    3. 除了主光源的其他重要光源在forwardadd Pass中逐像素渲染。
    4. 非重要光源会按照SH光方式，渲染进 UNITY_LIGHTMODEL_AMBIENT 变量中。
    5. 设置为important的光源一定会按照逐像素的方式渲染。
    6. unity最多会设置n个光源逐像素渲染，n为Edit -> Project Settings -> Quality中pixel light count的值。如果import光源大于n，所有auto的光源会按非重要光源渲染。

    帧调试器（frameDebugger）

    Window -> Analysis -> Frame Debugger

    2.2 光照纹理¶

    点光源和聚光灯计算光线衰减公式计算效率低，unity采用对光照衰减纹理进行采样进行优化。

        fixed3 lightDir = normalize(UnityWorldSpaceLightDir(i.worldPos));
    float3 lightCoord = mul(unity_WorldToLight, float4(i.worldPos, 1)).xyz;
    fixed atten = tex2D(_LightTexture0, dot(lightCoord, lightCoord).rr).UNITY_ATTEN_CHANNEL;
    _LightTexture0: 光照衰减纹理。

    3.1 投影和接收阴影¶

    投下阴影需要ShadowCaster Pass 

    Pass{
    Tags {"LightMode" = "ShadowCaster"}

    CGPROGRAM
    #pragma multi_compile_shadowcaster
    #pragma vertex vert
    #pragma fragment frag
    #include "UnityCG.cginc"

    struct v2f{
        V2F_SHADOW_CASTER;
    };

    v2f vert( appdata_base v){
        v2f o;
        TRANSFER_SHADOW_CASTER_NORMALOFFSET(o)
        return o;
    }

    float4 frag(v2f i):SV_Target
    {
        SHADOW_CASTER_FRAGMENT(i)
    }
    ENDCG
}
    接收阴影需要在BasePass中加入 1. SHADOW_COORDS：阴影纹理采样结果写入寄存器。 2. TRANSFER_SHADOW：阴影采样。 3. UNITY_LIGHT_ATTENUATION：获取阴影和光线衰减叠加后的衰减系数。

    struct v2f{
    ...
    SHADOW_COORDS(2);//2为寄存器编号，如0，1，2...
};

v2f vert(a2v v){
    v2f o;
    ...
    TRANSFER_SHADOW(o);
}

fixed4 frag(v2f i) : SV_Target{
    ...
    UNITY_LIGHT_ATTENUATION(atten, i, i.worldPos);
}
    物体Mesh Renderer处可以设置阴影接受配置
