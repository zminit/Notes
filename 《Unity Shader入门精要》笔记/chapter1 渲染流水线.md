# 1. 渲染流水线
**渲染流水线**
```mermaid
graph LR
    A([应用阶段]) --渲染图元--> B([几何阶段]) --顶点信息--> C([光栅化阶段])

```
### 1.1 应用阶段

- CPU将顶点数据从内存加载到显存
- 设置渲染状态（材质、纹理、着色器）
- 调用Draw Call，通知GPU执行指令

### 1.2 几何阶段

![alt text](../images/2025051401.png)
- 顶点着色器：空间变换、齐次裁剪（坐标归一化）
- 曲面细分着色器（可选）：细分图元
- 几何着色器（可选）：图元着色
- 裁剪：去除视锥之外的顶点
- 屏幕映射：获得顶点对应屏幕坐标，xy坐标缩放，z坐标不变
<img alt="图 2" src="../images/chapter1%20%E6%B8%B2%E6%9F%93%E6%B5%81%E6%B0%B4%E7%BA%BF1747204392873.png" />
>不同图形库坐标系起点不同


### 1.3 光栅化阶段
![alt text](../images/2025051402.png)
- 三角形设置：获取三角网格边界覆盖的像素坐标
- 三角形遍历：扫描变换，找出三角覆盖的像素（片元），对像素插值
- 片元着色：纹理采样...
- 逐片元操作/输出合并：模板测试、深度测试、混合
<img alt="图 3" src="../images/chapter1%20%E6%B8%B2%E6%9F%93%E6%B5%81%E6%B0%B4%E7%BA%BF1747205232263.png" />  

>光栅化的图元的颜色会储存在后置缓冲区，完成后与前置缓冲区交换

# 2 基础概念

**固定管线**：固定函数流水线
