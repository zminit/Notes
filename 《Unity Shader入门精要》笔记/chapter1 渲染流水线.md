# 1. 渲染流水线
**渲染流水线**
```mermaid
graph LR
    A([应用阶段]) --渲染图元--> B([几何阶段]) --顶点信息--> C([光栅化阶段])

```
### 1.1 应用阶段

- CPU将顶点数据从内存加载到显存
- 设置渲染状态（材质、纹理、着色器）
- 调用Draw Call，通知GPU执行指令

### 1.2 几何阶段

![alt text](附件/c1-1.png)
- 顶点着色器：空间变换、顶点着色
- 曲面细分着色器（可选）：细分图元
- 几何着色器（可选）：图元着色
- 裁剪：去除视锥之外的顶点
- 屏幕映射：投影变换，获得顶点对应屏幕坐标
