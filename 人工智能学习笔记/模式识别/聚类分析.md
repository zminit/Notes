# 1. 聚类测度


>**特征选择注意事项**
>- 特征选取不当无法准确分类。
>- 特征选取不足无法准确分类。
>- 特征选取过多回增加分类复杂度，并可能无法准确分类。
>- 量纲选取不当会导致分类结果不准确。

## 1.1 相似性测度

### 1.1.1 距离测度

>以矢量矢端距离作为度量的基础。两模式越相似，测度值越小。

**欧氏距离**

$d(\vec{x},\vec{y})=\sqrt{\sum_{i=1}^{n}(x_i-y_i)^2}$

- 欧氏距离具有平移和旋转不变性。

**绝对值距离**

$d(\vec{x},\vec{y})=\sum_{i=1}^{n}|x_i-y_i|$

**切比雪夫距离**

$d(\vec{x},\vec{y})=\max_{i=1}^{n}|x_i-y_i|$

**明氏距离**

$d(\vec{x},\vec{y})=[\sum_{i=1}^{n}|x_i-y_i|^m]^{\frac{1}{m}}$

$$切氏距离 \leq 欧氏距离 \leq 绝对值距离$$

**马氏距离**

$d^2(\vec{x},\vec{y})=(\vec{x}-\vec{y})^T\vec{V}^{-1}(\vec{x}-\vec{y})$

$x,y \in \{x_1,x_2,...,x_m\}$

$\vec{V}： 协方差矩阵，用于描述数据的分布情况。\frac{1}{m-1}\sum_{i=1}^{m}(\vec{x}_i-\vec{x})^T(\vec{x}_i-\vec{x})$

$\vec{x}： 矢量集平均值。\frac{1}{m}\sum_{i=1}^{m}\vec{x}_i$


- 马氏距离具有平移、旋转、缩放不变性。不受数据量纲影响。
- 一般$x,y$来自期望矢量为 $\mu$ , 协方差矩阵为 $\vec{V}$ 的母体 $G$。
- $x,y$来自两个数据集时，使用它们的互协方差矩阵。
- 协方差阵为单位阵时，马氏距离与欧氏距离相同。

### 1.1.2 相似测度

**角度相似系数**

$\cos(\vec{x},\vec{y}) = \frac{\vec{x}\cdot\vec{y}}{\|\vec{x}\|\|\vec{y}\|}$


### 1.1.3 匹配测度

**Tanimoto测度**

$s(\vec{x},\vec{y}) = \frac{x^T y}{x^T x +y^T y-x^T y}$

# 2. 聚类算法

## 2.1 简单聚类

1. 选取一个聚类中心，规定欧式距离阈值T。
2. 对每个数据点，计算它到聚类中心的距离。
3. 如果距离小于阈值T，则将该数据点分配到该聚类中心。若该点距离多个聚类中心距离均小于T，选择最近的一个。若距离均大于T，则该数据点为新聚类中心。
4. 重复以上步骤，直到所有数据点都被分配到聚类中心。

## 2.2 最大最小聚类

> 以最大距离选择聚类中心，最小距离进行模式归类。先算聚类中心，再归类。

1. 选择第一个聚类中心 $x_1$ 和比例系数 $\theta$ 。
2. 选择距离 $x_1$ 最远的点 $x_2$ 作为第二个聚类中心。
3. 计算剩余未被分类的点到 $x_1$ 和 $x_2$ 的距离的最小值，如果大于 $\theta \|x_1-x_2\|$ 就作为新的聚类中心。
4. 重复以上步骤，直到没有新的聚类中心出现。
5. 对剩余非聚类中心的数据点就近分配。

## 2.3 谱聚类

1. 将所有点作为聚类中心 。
2. 计算聚类两两之间的最小距离，选择距离最小的两个聚类中心合并。
3. 重复以上步骤，直到只剩两个聚类。

## 2.4 C-Means

1. 选择c个聚类中心。
2. 将待分类点就近分配。
3. 重新计算变化的聚类中心。
4. 重复以上步骤，直到所有点归类完毕。

## 2.5 K-NN

> 按照k个最近邻聚类种类最多的类别进行归类。
