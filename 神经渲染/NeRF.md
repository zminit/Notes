# 经典NeRF

>NeRF基本思想是通过空间中的自发光点云来拟合输入图片所代表的场景。使用神经网络不断拟合点云分布，最终得到一个函数 $f(\alpha,\beta,x,y,z) = (R, G, B)$ ，其中 $\alpha,\beta$ 是相机的旋转角度，$x,y,z$ 是空间坐标，$R, G, B$ 是颜色。

- 密度是怎么输出的？
- 为什么MLP颜色前的权重是PDF？

相机输入->世界坐标输入->


密度和位置有关

颜色和视角有关

所以输入的空间坐标位置编码需要10维，视角只需要4维，这两个是超参数。

$\gamma(p):60->256->256->256->256->256 + \gamma(x):60->256->256->256->256 + \gamma(d):24->128->RGB$

$实际\gamma(d):27 和\gamma(x):63$

x：空间坐标， d:视角坐标

$\gamma(p) = (sin(2^0\pi p), cos(2^0\pi p), sin(2^1\pi p), cos(2^1\pi p), ..., sin(2^{L-1}\pi p), cos(2^{L-1}\pi p))$

$$\hat{C(s)} = \int_{0}^{+\infty} T(s)\sigma(s)C(s) ds$$



- $T(s)$ 是在s点之前，光线没有被阻碍的概率。$T(s) = e^{-\int_{0}^{s}\sigma(t)dt}$。
- $\sigma(s)$ 在s点光线被阻碍的概率。
- $C(s)$ 在s处的点颜色。

离散化

$$\hat{C(s)} = \sum_{i=1}^{N} T_i(1-e^{-\sigma_i\delta_i})C_i$$


神经网络输入的是粒子的输入

粗模型：均匀采样，输出密度

细模型：根据密度，二次采样。

两个模型结构相同。

粗模型粒子颜色前的权重做softmax，得到PDF->CDF->invert cdf

每条光线上重新采样128个粒子，加上原来的64个粒子，得到192个粒子。
